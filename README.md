# 📡 Curso Web Moderno - Udemy

Repositório com exercícios, projetos e anotações feitos durante o curso **"Web Moderno Completo com JavaScript"** da [Udemy](https://www.udemy.com/course/curso-web/).

---

## 🎯 Objetivo

Organizar o estudo prático dos tópicos abordados no curso, com foco em **desenvolvimento Web moderno e completo**, do front-end ao back-end.

---

## ✅ Tecnologias Abordadas

- **HTML5**
- **CSS3** (Flexbox, Grid)
- **JavaScript (ES6+)**
- **Node.js**
- **Express**
- **React**
- **Vue.js**
- **Angular 9**
- **Bootstrap 4**
- **jQuery**
- **MySQL**
- **PostgreSQL**
- **MongoDB**
- **APIs REST**
- **Gulp**
- **Webpack**
